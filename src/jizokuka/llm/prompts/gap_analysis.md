# タスク: ヒアリングシートのギャップ分析

支援員が顧客から受け取ったヒアリングシートは、下記のとおり**単語レベル**でしか
埋まっていません。これを採択レベルの事業計画書に仕上げるために、
(A) 推論で埋められる事実 と (B) 本人に確認しないと書けない事項 に切り分けてください。

## 最重要の制約

**追加質問は最大 {max_questions} 件まで。** 支援員の工数削減が本システムの目的です。
「聞けば分かること」を全部聞くのではなく、**推論を間違えると採択可否に響く項目だけ**を
質問にしてください。業種の一般常識・地域特性・商流から合理的に推定できることは、
質問せずに `facts` として推定値を立ててください。

質問には**必ず選択肢を3〜5個**付けてください。顧客が選ぶだけで済むようにするのが目的です。
選択肢はあなたの推定に基づく現実的な候補にし、最後に「その他（自由記入）」的な逃げ道は
`allow_free_text` で表現するので選択肢自体には含めないでください。

## 出力形式（JSON のみ）

```json
{{
  "facts": [
    {{
      "key": "商圏人口",
      "value": "松本市の人口約24万人。店舗から半径5kmが主商圏と推定",
      "confidence": "inferred",
      "source": "address: 長野県松本市",
      "rationale": "所在地から一般的な和菓子小売の商圏半径を当てはめた"
    }}
  ],
  "questions": [
    {{
      "id": "q1",
      "text": "冷凍機を導入して最初に全国展開したい商品はどれですか",
      "why": "補助事業計画の有効性（対象商品が定まらないと効果の積算ができない）",
      "choices": ["どら焼き（主力・日持ち短い）", "季節生菓子（単価高・観光需要）", "大福（リピート率高）"],
      "allow_free_text": true,
      "impact": 5,
      "section": "sales_channel"
    }}
  ],
  "blocking": ["補助事業で何を買うのかが全く不明で、経費明細が作れない"]
}}
```

## 推論してはいけない項目

次は推論で埋めてはいけません。入力に無ければ **impact 5 の質問**にしてください。

- **競合他社の社名**（審査で「他社名を具体的に」と求められる項目。創作は事実誤認になる）
- 実在の取引先名・見積先名・金額
- 補助事業で購入する具体的な機器の型式と価格

ただし「競合が何社くらい存在するか」「どういう業態が競合になりうるか」は
業種知識から推論して `facts` に入れてください。聞くのは**社名と特徴だけ**です。

## 判断基準

- `facts` は多いほど良い（20〜40件を目安に、業種知識を総動員して埋める）。
  - `confidence` は `given`（シートに明記）/ `inferred`（推定）のいずれか。
  - 推定した数値には必ず `rationale` に推定方法を書く。
- `questions` の `impact` は採択への影響度 1〜5。5 は「これが無いと落ちる」。
  - impact 4 未満の質問は原則出さない（推論で埋める）。
- `blocking` は「推論では絶対に埋められず、計画書が成立しない」欠損のみ。
  該当なしなら空配列。
