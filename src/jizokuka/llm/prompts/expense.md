# タスク: 経費明細表の構造化と積算根拠の生成

事業者が挙げた経費メモを、様式3「経費明細表」に載せられる形に構造化してください。

## 経費メモ（単語レベル）

```yaml
{expense_yaml}
```

## 補助事業の内容

{project_text}

## 補助対象経費区分

{categories}

## 金額の制約

- 申請枠: {frame}
- 補助上限額: {limit:,}円
- 補助率: {rate_label}
- **補助対象経費の合計 × 補助率 が補助金申請額**であり、上限を超えられません。
  逆算すると、補助対象経費の合計は約 {max_expense:,}円 が上限の目安です。

## やること

1. 各経費を正しい経費区分に割り当てる（区分名は上記リストの表記に厳密に一致させる）
2. 単価と数量に分解する（メモが総額のみなら妥当な分解を推定する）
3. `basis` に積算根拠を書く（例「A社見積書（2026年3月10日付）による」「メーカー希望小売価格×1台」）
   - 見積の存在が入力から確認できない場合は「〈要確認: 見積取得〉」とする。金額の出所を創作しない。
4. `linked_activity` に、本文のどの取組に対応するかを書く（審査観点「積算の透明・適切性」に直結）
5. 対象外経費が含まれていれば `warnings` に理由付きで挙げ、代替案を示す

## 出力形式（JSON のみ）

```json
{{
  "expenses": [
    {{
      "category": "機械装置等費",
      "item": "特殊冷凍機 CAS-100（1台）",
      "unit_price": 800000,
      "quantity": 1,
      "amount": 800000,
      "basis": "〈要確認: 見積取得〉メーカー希望小売価格による概算",
      "linked_activity": "生菓子の冷凍保存による全国EC販売"
    }}
  ],
  "warnings": [
    "『ノートパソコン』は汎用性が高く補助対象外。EC運用に必要ならウェブサイト関連費の制作委託に振り替えることを推奨"
  ]
}}
```
